# Movie Ticket Fullstack Skill

## When to Use
Use this skill for tasks involving:
- Full project planning
- Backend + Flutter integration
- Movie booking flow
- API-to-UI connection
- Cross-module changes

## Required Context
Read:
- `docs/PROJECT_CONTEXT.md`
- `docs/AI_RULES.md`
- `docs/DATABASE_DESIGN.md`
- `docs/API_SPEC.md`

## Procedure
1. Identify whether the task affects backend, database, Flutter, or docs.
2. Check existing files before creating new ones.
3. Keep account security integrated with the movie booking product.
4. If backend API exists, Flutter must call real API.
5. If API changes, update `docs/API_SPEC.md`.
6. If schema changes, update `docs/DATABASE_DESIGN.md`.
7. Provide run/test steps.

## Output Format
- Affected files
- Short plan
- Code changes
- Run/test commands
- Notes for demo
